Keeping You in the Driver's Seat

CoCheck shows what AI agents changed in your files, step by step.

On a Macbrew install cocheck-ai/tap/cocheck cocheck install --home ~/CoCheckData
On a Mac or Windowsnpm install -g cocheck cocheck install --home ~/CoCheckData

--home must be an absolute path. On Windows, cmd and Windows PowerShell pass ~ through unexpanded, so use cocheck install --home "$env:USERPROFILE\CoCheckData" --for claude in PowerShell.

Run cocheck install from the folder you want CoCheck to watch, or pass --folder <dir>. Then restart your agent, start a session, say "start tracking", do some work, and say "show me the review".

How it works

  1. The agent works

    Your AI agent edits your files as usual. Nothing about your workflow changes.

  2. CoCheck records each change

    Every change is saved with the agent action that made it, one step at a time.

  3. You review before and after

    Open the review page, see each change next to the action responsible, and decide what stays.
